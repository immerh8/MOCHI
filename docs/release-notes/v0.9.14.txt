Pre-release of MOCHI 1.0. The installers now include the mochi command line, so you can use MOCHI from a terminal and in scripts without building it yourself. On Windows, setup puts mochi.exe in %LOCALAPPDATA%\MOCHI\bin and adds that folder to your user PATH: open a new terminal after installing and run "mochi --help". If your PATH is too long for setup to read in full, setup leaves it unchanged; the program is still installed there. Uninstalling removes the folder from PATH again. On Ubuntu the command is /usr/bin/mochi. Extracting is also fixed and faster: a large extraction no longer stays at "0% complete" and "Calculating time left", and archives with many small files extract much faster. A new setting, Settings > Speed > Fast extract (off by default), skips flushing each extracted file to disk one by one; that is faster on Windows, but after a power failure during extraction some files may be incomplete.
