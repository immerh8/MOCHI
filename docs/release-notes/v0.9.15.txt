Pre-release of MOCHI 1.0. Setup now records where the mochi command line is installed, so other programs can find it without relying on PATH: the Windows registry key HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\App Paths\mochi.exe holds the full path of mochi.exe (and, as "Path", its folder). This is Windows' standard place for a program's location; it also lets you start mochi from the Run dialog (Windows key + R). Uninstalling removes the key; updating keeps it current. Nothing changes on Ubuntu, where the command is /usr/bin/mochi.
