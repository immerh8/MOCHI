Pre-release of MOCHI 1.0. Extracting into a folder that already has some of the archive's files now asks one plain question instead of listing a paragraph per file. It names the files that are already there and offers: Add only new files (the default: folders that are there get what they are missing, and files that are there are left as they are), Replace (each file that is there goes to the Recycle Bin on Windows or the Trash on Ubuntu first, so you can get it back, and the archive's file takes its place), Extract to a new folder, or Choose another folder. Folders and links are never replaced, and an existing file is moved to the Bin only after the archive's copy has passed its checks; if it cannot be moved, it is kept and the result says so. Names that cannot be extracted on this computer are listed under a closed "can't extract" line with a short reason. The result line counts what was replaced, for example "Extracted 10 files · 1.2 KiB · 9 replaced". This works the same for MOCHI archives and for ZIP, 7z, RAR and tar files. Archives made by earlier versions open as before, and the mochi command line is unchanged.
