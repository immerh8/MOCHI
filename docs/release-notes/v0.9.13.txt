Pre-release of MOCHI 1.0. Fixes an archive that would not open: when MOCHI still had the archive open for a window whose page had gone back to the start screen (for example after the page reloaded), clicking it in Recent archives, choosing it in Open archive, or double-clicking it in Explorer did nothing at all. MOCHI now shows the archive in that window. If the window that had it is gone, the archive opens where you asked for it.
