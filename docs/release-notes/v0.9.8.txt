Pre-release of MOCHI 1.0. Each archive now opens in its own window, so two archives can be open side by side (an empty window is reused; an archive that is already open brings its window forward). Folder browsing has Back, Forward and Up buttons and a ".." row; "Close archive" no longer uses an arrow that looked like Back. "Extract to..." replaces Extract to Desktop: it remembers the folders you extracted into lately and starts on the Desktop the first time. New: Find in MOCHI archives (Explorer right-click on folders, Dolphin, Nemo, GNOME Files with python3-nautilus, or More > Find in archives, Ctrl+Shift+F) searches file names in every .mochi archive under the chosen folders; archives it could not search are listed and the search is marked incomplete. Adding to, opening and testing large archives is faster (adding one file to a 10,000-file archive: about 0.6 s before, 0.26 s now).
