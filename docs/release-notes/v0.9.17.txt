Pre-release of MOCHI 1.0. Easier to find your way and to extract. The toolbar shows a word beside each icon (Open, Add, Extract to, Test, Find) whenever the window has room, and icons only when it is narrow. When files are selected, Extract to, Remove and Info appear in the bar at the bottom, next to the number selected, with a button to clear the selection. Extract to now starts on the Desktop; a folder you type that does not exist yet is created when you press OK; and a line under the folder says what will happen before you press it, for example that a folder named after the archive is already there, so a new one is made with a number, such as "photos (2)". Nothing already in a folder is replaced. After an extraction, the folder opens in a new file manager window; untick "Open the folder when done" to stop that, and the choice is remembered. After "Extract to a new folder" from the right-click menu, you can rename the new folder or move it to another folder on the same drive from the small window. Archives made by earlier versions open as before, and the mochi command line is unchanged.
